# structure/hexDock/

Hex docking wrappers (protein–protein).

| File | Role |
|------|------|
| `hexdock.sh` | Shell driver to run Hex |
| `hexdock_template.mac` | Hex macro / input template |

Usage (edit paths inside the script / template first):

```bash
bash hexdock.sh
```
